# Kivy Snake Game

A Python game using Kivy where you control a snake to eat food, grow longer, and avoid running into walls or yourself. Perfect for learning GUI programming and game logic.

---

## Features

- Move the snake using arrow keys (or swipe/touch, if adapted for mobile)
- Regular food spawns randomly; eating food increases snake’s length
- Game over on collision with walls or self
- Score tracking: displays current score and high score

---

## Requirements

- Python 3.x
- Kivy

---

## Installation

Clone the repository:

python3 -m venv .venv
source .venv/bin/activate # macOS / Linux

# .venv\Scripts\activate # Windows

pip install -r requirement.txt

python3 snake_game.py
